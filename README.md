# HideIt

## How To Install
1. Download the latest HideIt .zip file
2. Extract the ZIP file to a folder on your computer.
3. Open your browser's extensions page:
4. Enable Developer mode.
5. Click Load unpacked.
6. Select the extracted HideIt folder containing manifest.json.

## Important
Since these are unpacked extensions you need to keep them on your computer or else the extension stops working, I recommend putting it in a folder you know you won't delete. I have put mine in a folder in my Documents directory.

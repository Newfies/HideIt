## Features
- Case sensitive option
- A "Streamer mode" option that hides the blacklisted terms when clicking the extension

## How To Install [.crx]
1. Download the latest HideIt .crx file
3. Open your browser's extensions page
4. Enable Developer mode.
5. Drag the .crx file into the extension page
> [!IMPORTANT]
> Brave Browser doesn't allow for dragging .crx files like this so if you use Brave you must use the other method of installing the extension.


## How To Install [.zip / Unpacked Extension]
1. Download the latest HideIt .zip file
2. Extract the ZIP file to a folder on your computer.
3. Open your browser's extensions page
4. Enable Developer mode.
5. Click Load unpacked.
6. Select the extracted HideIt folder containing manifest.json.
> [!IMPORTANT]
> Since its an unpacked extensions you need to keep them on your computer or else the extension stops working, I recommend putting it in a folder you know you won't delete. I have put mine in a folder in my Documents directory where I keep all my other unpacked extensions.
